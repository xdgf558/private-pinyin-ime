# STORE-01 截图清单

App Store Connect 每组支持 1–10 张不带 alpha 通道的 PNG/JPEG。当前 target 同时支持 iPhone 和 iPad，因此两组都是正式提审必需项。

## 尺寸

- iPhone 6.9 英寸竖屏：`1320 x 2868`、`1290 x 2796` 或 `1260 x 2736`
- iPad 13 英寸竖屏：`2064 x 2752` 或 `2048 x 2732`

## 建议顺序

1. 容器 App 总览：开始使用、隐私与学习、词库管理、关于。
2. 全键盘输入：显示 `nihao` 和“你好”候选。
3. 九宫格输入：显示 `64426` 的可读拼音组合和“你好”候选。
4. 展开候选：显示多行候选页，不包含个人对话或真实账号内容。
5. 隐私与学习：显示“键盘扩展不联网”、学习开关、纠错和宽容拼音。
6. 词库管理：显示本地 Rime 导入和主动雾凇精选导入。

## 发布检查

- [ ] 截图来自 `1.0.0 (27)` 候选版。
- [ ] 不出现 TestFlight、调试探针、内部状态或占位文案。
- [ ] 不出现真实姓名、头像、邮箱、手机号、对话或社交账号。
- [ ] 状态栏、旋转方向和深色外观一致。
- [ ] PNG/JPEG 没有 alpha 通道，像素尺寸通过 App Store Connect 校验。
