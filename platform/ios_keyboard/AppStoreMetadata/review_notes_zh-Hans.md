# App Review 审核备注

猫栈拼音是一款不需要登录的 iOS/iPadOS 中文键盘。

审核步骤：

1. 打开猫栈拼音容器 App，在“开始使用”页点击“打开键盘设置”。
2. 在“设置 > 通用 > 键盘 > 键盘 > 添加新键盘”中添加“猫栈拼音”。
3. 不需要也不应开启“允许完全访问”；本扩展的 `RequestsOpenAccess` 为 `false`。
4. 在备忘录或容器 App 内的文本框中切换到猫栈拼音。
5. 全键盘输入 `nihao`，首选应显示“你好”；九宫格输入 `64426`，应可选择“你好”。
6. 点击候选条右侧的下拉入口，可查看更多候选。
7. 容器 App 的“隐私与学习”页可关闭或清除本机学习记录，并可打开隐私政策和支持页。

网络和隐私：

- 键盘扩展本身不使用网络 API，不收集或上传用户输入内容。
- 拼音转换、候选排序、智能纠错和用户学习均在设备本地完成。
- 容器 App 只在用户主动选择“下载并导入”时，从固定 GitHub 官方来源下载经审核的 Rime 词库；不会发送输入内容、学习记录或设备标识符。
- 应用不含账号、订阅、广告、追踪或云端服务。

无需演示账号。如果需要协助，请使用 App Store Connect 中的审核联系信息。
